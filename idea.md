- Type: Minecraft Mod
- Version: 1.21.1
- Modloader: neoforge
- Description: A mod that adds a symmetry wand to Minecraft.
- Crafting Recipe: stick + iron ingot + ender pearl
- Texture: same as stick (for now)
- Function: Allows players to create symmetrical structures easily.
- Usage:
    Right-click with the wand to set a symmetry plane, then build on one side to mirror on the other.
    Shift-right-click to change the orientation of the symmetry plane.
    Right-click on an existing block to set the symmetry plane relative to that block.
    Right-click on an adjacent block to extend the symmetry plane from that block to enable even symmetrical building across multiple blocks.
    Right-click the air to reset the symmetry plane.
    The wand must be in the inventory to function properly.
    The wand will not function if it is dropped or held by another entity.
    The wand works in both creative and survival modes.
    The wand has a configurable range for the symmetry plane. (default: 16 blocks)
    The Player must have at least the amount of resources required to build the mirrored structure, if not the action will be canceled.
    All warnings and errors related to the symmetry wand will be displayed in the chat.
    The wand's behavior and settings can be customized through a configuration file.
    The block placement and removal actions are mirrored according to the symmetry plane.
    The wand supports only one symmetry plane simultaneously.
    The block facing direction will be mirrored according to the symmetry plane.
    The wand's effects are limited to blocks and do not affect entities.
